# SENTINEL AI — Brand Voice & Editorial Guidelines

**Document Version:** 1.0.0  
**Status:** CANONICAL VOICE MANUAL  

---

## 1. Brand Personality & Tone

SENTINEL is an autonomous security intelligence system. It speaks with:

- **Quiet Confidence**: We let factual telemetry and verified outcomes demonstrate capability. We never plead for attention or boast about "game-changing" technology.
- **Technical Precision**: We use exact cybersecurity terms (*telemetry*, *signals*, *evidence*, *mitigations*, *attributions*) without obfuscation or decorative jargon.
- **Intelligence & Economy**: Short, declarative sentences. Minimal supporting text. Every sentence must justify its inclusion.
- **Authority**: High-end software speaks with restrained conviction, like Apple product documentation, Linear, and Stripe.
- **Strict Honesty**: We clearly distinguish observed telemetry from analytical hypotheses, recommendations from approved policy, and simulated dry runs from verified production executions.

---

## 2. Terminology Standards

Always use canonical product terminology. Never alternate arbitrarily between synonyms.

| Concept | Canonical Term | Deprecated / Disallowed Terms |
| :--- | :--- | :--- |
| Forensic investigation records | **Investigation** | *Case*, *Ticket*, *Task*, *Query* |
| Ingested raw occurrences | **Signals** / **Telemetry** | *Data points*, *Hits*, *Logs dump* |
| Correlated proof points | **Evidence** | *Info*, *Stuff*, *Reasons* |
| High-priority threat groupings | **Incidents** | *Issues*, *Problems*, *Alert storms* |
| Behavioral anomaly flags | **Detection** | *Finding*, *Notices*, *Flags* |
| Severity quantification | **Assessment** | *Verdict*, *Guess*, *Prediction* |
| Defensive countermeasure | **Response** / **Mitigation** | *Fix*, *Remedy*, *Action item* |
| Real-time stream of incoming events | **Activity** | *Live Feed*, *Ticker*, *Timeline* |
| SOAR execution verification | **Verification** / **Verified** | *Success check*, *Double-check* |
| Compliance history | **Audit trail** | *Changelog*, *History tab* |

---

## 3. Strict Style & Editorial Rules

1. **No Emojis Anywhere**: Emojis undermine technical credibility in mission-critical security platforms.
2. **No Superficial Superlatives**: Strip words like *groundbreaking*, *seamless*, *cutting-edge*, *ultimate*, *game-changer*, *intelligent* (when self-referential).
3. **No Phony Marketing Slogans**:
   - ❌ "Your security, reimagined."
   - ❌ "The future of cybersecurity."
   - ❌ "AI-powered protection for everyone."
   - ❌ "Secure your digital world."
   - ❌ "Unlock the power of AI."
   - ❌ "Your security operations, simplified."
   - ❌ "One platform. Endless possibilities."
4. **Behavioral Descriptions Only**: Write what the product actually does:
   - ✔️ *"Every signal has a story. Find it."*
   - ✔️ *"Investigate an event. Trace an attack. Understand the evidence."*
   - ✔️ *"Detection is only the beginning."*
   - ✔️ *"Sentinel is standing by."*
   - ✔️ *"Describe an event or begin an investigation..."*

## 4. Microcopy Guidelines

| Context | Before (Generic) | After (Precise & Restrained) |
| :--- | :--- | :--- |
| Empty event list | "No data available." | "No telemetry received." |
| Empty incident queue | "No incidents found." | "No active incidents." |
| Network error | "Something went wrong." | "Connection interrupted. Retry ingestion." |
| Search prompt | "Search anything..." | "Search signals, assets, or techniques..." |
| Loading prompt | "AI is thinking..." | "Correlating telemetry across forwarders..." |
| Button CTA | "Click to fix" | "Execute Mitigation" |
| Dry run status | "Simulated OK" | "Dry Run Verified" |
